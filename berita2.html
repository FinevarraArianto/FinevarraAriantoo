Hari Kereta Api Nasional Diperingati Setiap 28 September

28 September 2026

Hari Kereta Api Nasional diperingati setiap tanggal 28 September. Peringatan ini berkaitan dengan peristiwa pada 28 September 1945, ketika para pegawai perkeretaapian dan Angkatan Muda Kereta Api mengambil alih Kantor Pusat Kereta Api di Bandung dari kekuasaan militer Jepang.

Peristiwa tersebut menjadi salah satu bagian penting dalam sejarah perkeretaapian Indonesia setelah Proklamasi Kemerdekaan. Setiap tahunnya, tanggal 28 September diperingati sebagai Hari Kereta Api Nasional untuk mengenang sejarah perjuangan para pekerja perkeretaapian Indonesia.
